2026年4月27日（月）13:00-18:00

## このページについて

Bootcampのハンズオン用教材とセットアップ手順をまとめています。
**当日はこのページから順にお進みください。**

## 進め方

### ① 環境セットアップ
Databricks Free Edition環境の登録と、このGitHubリポジトリのクローンを行います。
講師の指示に従って [setup.md](setup.md) の手順を実施してください。

### ② 前半：AI/BI ハンズオン（川嶋講師）
Databricks Free Edition上で、ダッシュボード作成とGenieでのデータ分析を体験します。
会場でサンプルデータを用意しています。

### ③ 後半：データエンジニアリング ハンズオン（赤塚講師）
以下のノートブックを使って、メダリオンアーキテクチャの構築を体験します。

| ノートブック | 内容 |
|---|---|
| [notebooks/00_main.py](notebooks/00_main.py) | Bronze→Silver→Gold層の構築、Time Travel、Lakeflow Jobs |
| [notebooks/01_ai_data_processing.py](notebooks/01_ai_data_processing.py) | ai_classify / ai_queryを使ったAIデータ加工 |
